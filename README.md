# EcoQuest – Gamified Environmental Education Platform 🌱

## Overview
EcoQuest is an AI-powered gamified environmental education platform designed for schools and colleges. It helps students learn environmental concepts through interactive lessons, quizzes, AI assistance, and gamification features.

## Features
- Secure User Authentication
- Role-Based Access Control (Admin, Teacher, Student)
- Environmental Learning Modules
- Interactive Quiz System
- Quiz Timer & Score Calculation
- AI Environmental Assistant (EcoBuddy)
- Personalized Learning Recommendations
- Daily Eco Tips
- Performance Analytics
- XP, Levels, Badges & Leaderboard
- Student Progress Dashboard

## Technologies Used
### Frontend
- React
